# Release notes — v0.1.0-stage3.6

Initial public research snapshot.

Included:

- Stage 1–3.6 source and configuration files;
- compact reports, figures, aggregate metrics, experiment registries, vocabularies, static embeddings, and training logs;
- the small Stage 3 prototype checkpoint in Git;
- four Element2Vec V2 checkpoint files delivered as release assets (large files are automatically reassembled from 64 MiB parts);
- environment, bootstrap, checksum, dataset-placement, reproducibility, rights, and agent-handoff documentation.

Excluded:

- all raw and processed datasets;
- whole-rock and pyrite sample records;
- sample-level embeddings, latents, coordinates, spaces, caches, fitting pools, and projection models;
- local environments and credentials.

Scientific state: one strict PCA32/PCA64 low-rank recovery is supported for the single-element finite-difference experiment. Other geological structure is local, confounded, preserved rather than enhanced, projection-sensitive, or visualization-only. See `EXPERIMENT_STATUS.md`.
