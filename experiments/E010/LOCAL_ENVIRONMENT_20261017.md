## 使用与边界

日常命令见 [环境说明](../../environments/local-cpu/README.md)。需要在新终端使用 uv，或刷新已打开终端的用户 PATH 与用户环境变量。数值库默认线程为 1，直接运行的 Matplotlib 缓存在项目环境内，经 `experiment.py exec` 执行时使用各 run 的缓存。

全量准备作为下一项独立任务：本地新建 run、准备、核验、冻结并登记新资产；此处验收 run 不是准备资产。HPC 文件管理节点只承担集群允许的文件传输与提交操作，禁止 Python、环境检查、运行登记、哈希或数据准备。新提交接口 `e010_a800.sh new` 在计算节点作业内登记协调 run；恢复使用原协调 run。当前没有 Slurm/A800 实机验收，仍仅计划执行原扫描后 12 项、四个单卡队列。
